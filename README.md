# Resume Developer Website
live url:(https://resume-developer-website.vercel.app/)
A personal resume and portfolio website built to showcase skills, projects, and professional experience as a software developer.

---

## Features

- Clean and modern UI
- Fully responsive design (desktop, tablet, mobile)
- Projects and experience showcase
- Skills and technology stack section
- Contact information and social links
- Fast performance and SEO-friendly structure

---

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui

---

## Getting Started

### Prerequisites
- Node.js (v22 or v24 recommended)
- npm or yarn

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate into the project directory
cd resume-developer-website

# Install dependencies
npm install

# Start the development server
npm run dev
```
